# myonline page

## Как выложить на GitHub Pages

1. Создай репозиторий (например `myonline`) и загрузи содержимое этой папки в корень репозитория.
2. В GitHub открой `Settings -> Pages`.
3. В `Source` выбери `Deploy from a branch`.
4. Выбери ветку `main` и папку `/ (root)`.
5. После публикации сайт будет доступен по адресу:
   `https://YOUR_GITHUB_USERNAME.github.io/myonline/`
6. В `main.py` замени константу `MYONLINE_DETAILS_URL` на свой настоящий URL.
7. Страница получает статистику через URL-параметр `d`, который автоматически формирует бот в кнопке `Подробнее`.
8. Не открывай вручную пустой URL для проверки логики статистики; используй переход из `/myonline` в боте.
